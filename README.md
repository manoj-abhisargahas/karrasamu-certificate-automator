# Karrasamu Certificate Automator
To automate the printing of 700 certificates populated by players results data maintained in Excel sheets, this project was created when I was providing my freelancing services as Technical Lead for KFI's (Karrasamu Federation of India) 1st National Karrasamu Championship-2024.
